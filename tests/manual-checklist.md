# FitLife Manual Test Checklist

Open the project through a local server and complete these checks after major changes.

## Navigation and responsive layout

- Open every navigation link on desktop.
- Resize to tablet, mobile, and 320 px widths.
- Open and close the mobile menu.
- Verify outside click and Escape close the menu.
- Confirm the current page is highlighted.

## Signup and login

- Create a demo account.
- Try one incorrect login.
- Log in successfully.
- Confirm the navbar greeting appears.
- Click the greeting and log out.

## BMI and macros

- Calculate one valid BMI and macro result.
- Reload each page and verify the last result returns.
- Reset each calculator.
- Try invalid or incomplete values.

## Attendance

- Add an attendance record.
- Try adding the same name and date twice.
- Search by member name.
- Filter by date.
- Delete one record.
- Export the CSV.
- Clear all records.

## Workouts

- Switch between all three workout levels.
- Complete multiple workout days.
- Reload and verify completed days remain selected.
- Click a completed day again to undo it.

## Meal plans

- Switch between all three fitness goals.
- Switch between vegetarian and non-vegetarian plans.
- Verify each selection shows the correct cards.

## Contact and other interactions

- Submit the contact form and confirm the saved-message notice.
- Open membership FAQs.
- Show trainer availability.
- Test password visibility buttons.
- Verify toast messages do not block the page.
